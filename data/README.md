# Data

The dataset is **not** stored in this repository (the CSV is ~150 MB, above GitHub's file-size limit).

**Option 1: automatic.** If `data/creditcard.csv` is missing, the notebook downloads it with
[`kagglehub`](https://github.com/Kaggle/kagglehub) (you need a Kaggle account and API credentials the first time).

**Option 2: manual.** Download `creditcard.csv` from
[Kaggle: Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) and place it in this folder.

---

**Les données ne sont pas versionnées** (CSV d'environ 150 Mo). Le notebook les télécharge avec `kagglehub` si
`data/creditcard.csv` est absent, ou placez-y le fichier téléchargé depuis Kaggle.
